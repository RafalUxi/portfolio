# Portfolio

https://rafaltrzeciakowski.dev/

My developer portfolio. Two views: a dashboard with a physics-based
skill container, an interactive map of where I studied and worked, and
a small browser game, plus a projects section with a file-tree
navigation.

Polish and English, switchable.

## Running locally

```bash
npm install
npm run dev
```

The app runs on `http://localhost:5173`.
